A one-day news image for Tuesday 17 November 2026, drawn as a newspaper front page: Ukraine's 1,300-drone strike on the Crimea bridge, Iran's drone attack on a U.S. radar in Bahrain, a worldwide stocks slide, the confirmed Xi–Trump–Putin meeting in Shenzhen, the COP31 fossil-fuel draft, Robert Pattinson as the new James Bond, and Amazon's lost satellites. The stories were researched from Reuters, Al Jazeera, AP, AFP and Just Security coverage of the day and are baked into `tools/stories.json`; `tools/render.py` draws the 1024×1024 image with Pillow, no network needed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To redraw the image from the stories file:

```sh
python3 tools/render.py
```
